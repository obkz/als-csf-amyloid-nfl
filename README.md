# Analysis scripts for the ALS CSF amyloid and neurodegeneration biomarker study

This repository contains R scripts used for the statistical analyses and visualisation in the following study:

**Publication:** Obara K, et al. "Cerebrospinal fluid amyloid and neurodegeneration biomarkers in the diagnosis and prognosis of amyotrophic lateral sclerosis: a multicohort observational study." *eBioMedicine*. 2026 (in press).

## Repository contents

- `scripts_pub/`: R scripts for statistical analyses and figure/table generation.
- `README.md`: Overview of the repository.
- `.gitignore`: File exclusion rules for data and output files.

## Supplementary table numbering

Supplementary table numbering changed during manuscript revision. Existing objects retain their original numbering, while objects added during revision use the `_added` suffix. Please refer to `scripts_pub/09_final_suppleT_list.R` for the correspondence with the final manuscript.

## Data availability and reproducibility

The scripts are shared to improve transparency regarding the analytical workflow. They are not intended to provide a fully executable reproduction package without access to the underlying study data.

Individual-level clinical and biomarker data are not included because of institutional and legal restrictions on patient data confidentiality. Please refer to the article's Data Sharing Statement for details on data availability.
